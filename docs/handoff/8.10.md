# 8.10 — Client: Sovereign Mode Toggle

## What was done

Added a "Sovereign Mode" toggle to the Electron client Settings page. When enabled, the client treats the BoilerDeck gateway as just another relay and fetches listings from all enabled relays. When disabled (default), all data comes from the gateway as the standard experience.

## Files changed

- `client/src/main/store.ts` — Added `sovereignMode?: boolean` to `StoreData` interface and `"sovereignMode"` to `STORE_KEY_WHITELIST`
- `client/src/main/index.ts` — Added IPC handlers `settings:get-sovereign-mode` and `settings:set-sovereign-mode`
- `client/src/main/preload.ts` — Added `sovereignty` section to preload bridge and matching type declarations
- `client/src/renderer/env.d.ts` — Added `sovereignty` type declarations
- `client/src/renderer/pages/Settings.tsx` — Added Sovereign Mode section with toggle, descriptive text, and warning box

## How it works

- **Store key:** `sovereignMode` (boolean, default `false`)
- **IPC channels:** `settings:get-sovereign-mode` (read), `settings:set-sovereign-mode` (write)
- **Preload API:** `window.boilerdeck.sovereignty.getMode()` / `.setMode(enabled)`
- **UI placement:** Between "Relays" and "About" sections in Settings
- **OFF state:** Shows "All data comes from the BoilerDeck gateway. This is the standard experience."
- **ON state:** Shows relay aggregation description + amber warning about unavailable features (payments, cloud saves, developer portal, automatic updates)

## What's next

- 8.11 (Graceful gateway-down handling) will auto-activate sovereign mode when the gateway is unreachable
