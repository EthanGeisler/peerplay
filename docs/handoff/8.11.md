# 8.11 — Resilience: Graceful gateway-down handling

## What was done

### Listing cache layer (Electron store)
- Added `cachedListings` to `STORE_KEY_WHITELIST` and `StoreData` interface in `client/src/main/store.ts`
- Shape: `{ listings: unknown[]; cachedAt: string }` (ISO timestamp)

### Cache IPC handlers (`client/src/main/index.ts`)
- `cache:get-listings` — returns cached listings from Electron store (or null)
- `cache:set-listings` — saves listings array with current timestamp

### Preload bridge + type declarations
- Added `window.boilerdeck.cache` namespace with `getListings()` and `setListings()` in:
  - `client/src/main/preload.ts` (implementation + declare global)
  - `client/src/renderer/env.d.ts` (renderer type declaration)

### Game store resilience (`client/src/renderer/stores/gameStore.ts`)
- On successful fetch (both gateway and sovereign mode): caches listings via `window.boilerdeck.cache.setListings()` (fire-and-forget)
- On fetch failure: attempts to load cached listings
  - If cache exists: uses cached data, sets `gatewayDown: true`, `usingCache: true`, `cacheAge` (human-readable)
  - If no cache: sets empty state with `gatewayDown: true`, `usingCache: false`
- New state fields: `gatewayDown`, `usingCache`, `cacheAge`
- `formatCacheAge()` helper converts ISO timestamp to "just now", "5m ago", "2h ago", "3d ago"

### Gateway-down banner (`client/src/renderer/pages/Store.tsx`)
- Amber/yellow banner when `gatewayDown` is true
- With cache: "Gateway unavailable -- showing cached data from {cacheAge}. Installed content is still accessible."
- Without cache: "Gateway unavailable. Your installed content is still accessible from the Library."
- Dismissible via X button; resets when gateway status changes

### Installed games (no changes needed)
- Game launch works without network — `installedStore.launch()` spawns the exe directly via `games:launch` IPC
- Installed games data is persisted in Electron store (`installedGames` key), not fetched from gateway
- In-progress torrent downloads continue via P2P (WebTorrent is peer-to-peer; gateway is only needed to get the initial magnet URI)

## Files changed
