# Sub-task 1.9 — Frontend: mnemonic display on registration (web)

## What was built
- **`web/src/types.ts`** — added `mnemonic?: string` to `ApiAuthResponse`, `nostrPubkey?: string` to `ApiUser`
- **`web/src/stores/authStore.ts`** — `register()` now returns the mnemonic string from the API response
- **`web/src/components/MnemonicModal.tsx`** — new modal component for displaying the 12-word recovery phrase
- **`web/src/pages/Login.tsx`** — shows MnemonicModal after registration if mnemonic is present

## Key decisions made during implementation
- **Modal blocks navigation.** After registration, the user stays on the login page with the modal overlay. Navigation to "/" only happens when the modal is dismissed (via "Continue" or "I'll do this later").
- **Mnemonic lives only in React state.** `useState<string | null>` in Login.tsx — never touches localStorage, sessionStorage, or any persistent storage. Cleared when modal closes.
- **Two-click escape hatch.** "I'll do this later" requires two clicks — first shows a warning, second dismisses. This prevents accidental skipping.
- **Confirmation checkbox gates "Continue".** The primary dismiss button is disabled until the user checks "I have saved my recovery phrase."

## How it works

### Registration flow
```
User fills form → submits → register() API call
  → API returns { user, accessToken, refreshToken, mnemonic }
  → Tokens stored, user set in store
  → mnemonic set in local state → MnemonicModal renders
  → User saves phrase → checks checkbox → clicks "Continue"
  → mnemonic cleared from state → navigate("/")
```

### MnemonicModal features
- 12 words in a 3-column grid with numbered labels
- "Copy to Clipboard" button (shows "Copied!" for 2s)
- Confirmation checkbox: "I have saved my recovery phrase"
- "Continue" button: disabled until checkbox is checked
- "I'll do this later": first click shows red warning, second click dismisses
- Uses existing design tokens (--bg-secondary, --accent, --border, etc.)

## Gotchas and surprises
- **`register()` return type changed from `Promise<void>` to `Promise<string | undefined>`.** The mnemonic is returned from the store action so Login.tsx can capture it in local state.
- **No modal on login.** This sub-task only handles registration. Sub-task 1.10 adds the same modal for login (lazy migration case).
