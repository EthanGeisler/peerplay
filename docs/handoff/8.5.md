# 8.5 — Server: Federation — subscribing to external relays (listing-level)

## What was done

### 1. Listing-level federation via REST polling (`federation.ts`)
- `initFederation()` is now `async` — upserts each `EXTERNAL_RELAYS` URL into the `Relay` DB table on startup
- `pollRelayListings(relay)` — fetches `GET <relayUrl>/api/relay/listings?limit=100`, verifies Schnorr signatures on listings that have `creatorPublicKey` + `signature`, upserts into `db.federatedListing`
- `startListingPoll(relay)` — immediate first poll + recurring interval via `setInterval`
- `verifyListingSignature()` — canonical format: `JSON.stringify({ title, slug, description, priceCents, contentType })`, SHA-256 hashed, Schnorr verified
- `updateRelayStatus(url, status)` — updates `lastSyncAt` and `status` in `Relay` table after successful poll
- `addRelay(url)` / `removeRelay(url)` — manage in-memory federation map (used by admin API)
- Poll interval: `FEDERATION_POLL_INTERVAL_MS` env var (default: 300000 = 5 minutes)

### 2. Admin API for relay management (`routes.ts`)
- `GET /api/admin/relays` — list all relays (ADMIN only)
- `POST /api/admin/relays` — add a relay (`url`, `name`, `trustedByDefault`). Validates ws:// or wss:// protocol. Upserts into DB and adds to in-memory federation.
- `DELETE /api/admin/relays/:id` — remove a relay from DB and disconnect from federation

### 3. Config change (`shared/src/config.ts`)
- Added `FEDERATION_POLL_INTERVAL_MS` (coerced number, default 300000)

### 4. Server startup (`server/src/index.ts`)
- `initFederation()` call now handles the returned Promise (`.catch()` for error logging)

## Files changed
- `server/packages/relay/src/federation.ts` — listing polling, relay DB sync, add/remove helpers
- `server/packages/relay/src/routes.ts` — admin relay CRUD routes
- `server/packages/relay/src/index.ts` — exports `addRelay`, `removeRelay`, `pollRelayListings`, `updateRelayStatus`
- `server/packages/shared/src/config.ts` — `FEDERATION_POLL_INTERVAL_MS` env var
- `server/src/index.ts` — async `initFederation()` call

## Env vars
- `FEDERATION_POLL_INTERVAL_MS` — polling interval in ms (default: 300000 = 5 min)
- `EXTERNAL_RELAYS` — comma-separated WSS URLs (existing, now also upserted into Relay DB table)

## URL mapping
WebSocket relay URLs are converted to HTTP for REST polling:
- `wss://relay.example.com/relay` -> `https://relay.example.com/api/relay/listings`
- `ws://localhost:3001/relay` -> `http://localhost:3001/api/relay/listings`
