# Sub-task 1.2 — Crypto utility module

## What was built
- **`server/packages/auth/src/crypto.ts`** (NEW) — all cryptographic utilities for Nostr-compatible keypair identity
- **`server/packages/auth/src/index.ts`** — added re-exports of all 12 crypto functions

## Key decisions made during implementation
- **Shared internal `encryptBytes`/`decryptBytes`** — `encryptPrivateKey` and `encryptMnemonic` are thin wrappers over the same AES-256-GCM logic. Avoids code duplication while keeping the public API type-safe (Uint8Array vs string).
- **`maxmem` required for scrypt** — Node.js default `maxmem` is 32 MB, which is exactly `128 * N * r` for our params (N=32768, r=8). This causes `ERR_CRYPTO_INVALID_SCRYPT_PARAMS` on the boundary. Fixed by setting `maxmem: 128 * N * r * 2` (64 MB).
- **scrypt params hardcoded as constants** tied to `v1` format prefix. Changing them requires a new format version.

## How it works

### Key generation flow
```
generateMnemonic() → 12-word BIP39 english mnemonic
    ↓
mnemonicToKeypair(mnemonic)
    → mnemonicToSeedSync(mnemonic) → 64-byte seed
    → HDKey.fromMasterSeed(seed).derive("m/44'/1237'/0'/0/0")
    → privateKey = hdkey.privateKey (32 bytes)
    → publicKey = hdkey.publicKey.slice(1) (drop 02/03 prefix → 32-byte x-only)
```

### Encryption format (v1)
```
v1:salt(32B hex):nonce(12B hex):tag(16B hex):ciphertext(hex)
```
- Key derivation: `scryptSync(password, salt, 32, { N: 32768, r: 8, p: 1 })`
- Cipher: AES-256-GCM with 12-byte random nonce
- Auth tag extracted separately via `cipher.getAuthTag()` (Node crypto doesn't concatenate it)

### Exported functions
```ts
// Generation
generateMnemonic(): string
mnemonicToKeypair(mnemonic: string): { publicKey: Uint8Array, privateKey: Uint8Array }
generateKeypair(): { mnemonic: string, publicKey: Uint8Array, privateKey: Uint8Array }

// Encryption
encryptPrivateKey(privateKey: Uint8Array, password: string): string
decryptPrivateKey(encrypted: string, password: string): Uint8Array
encryptMnemonic(mnemonic: string, password: string): string
decryptMnemonic(encrypted: string, password: string): string

// Signing
schnorrSign(privateKey: Uint8Array, messageHash: Uint8Array): Uint8Array  // 64-byte sig
schnorrVerify(publicKey: Uint8Array, messageHash: Uint8Array, signature: Uint8Array): boolean

// Encoding
pubkeyHex(publicKey: Uint8Array): string        // 64 hex chars, lowercase
pubkeyToNpub(publicKey: Uint8Array): string      // bech32 "npub1..."
privkeyToNsec(privateKey: Uint8Array): string    // bech32 "nsec1..."
```

## Gotchas and surprises
- **`@scure/bip39` wordlist import requires `.js` suffix:** `@scure/bip39/wordlists/english.js` (NOT `@scure/bip39/wordlists/english`). The package's `exports` map mandates this.
- **`@noble/hashes` v2 rejects string input:** `sha256('hello')` throws. Must pass `Uint8Array`: `sha256(new TextEncoder().encode('hello'))`. All downstream code (event hashing in Phase 2) must use explicit byte conversion.
- **Node scrypt `maxmem` boundary:** N=32768, r=8 requires exactly 32 MB which equals Node's default limit. Must set `maxmem` explicitly or the call fails.
- **`schnorr.sign()` argument order:** `schnorr.sign(messageHash, privateKey)` — message first, key second. Our wrapper `schnorrSign(privateKey, messageHash)` normalizes this to key-first for consistency with the rest of the API.
- **`schnorr.verify()` argument order:** `schnorr.verify(signature, messageHash, publicKey)` — sig first. Our wrapper normalizes to `schnorrVerify(publicKey, messageHash, signature)`.

## How to use / test
```bash
# Quick smoke test (from repo root)
node --import tsx --input-type=module -e "
import { generateKeypair, encryptPrivateKey, decryptPrivateKey, schnorrSign, schnorrVerify, pubkeyHex, pubkeyToNpub } from './server/packages/auth/src/crypto.ts';
import { sha256 } from '@noble/hashes/sha2.js';
const { mnemonic, publicKey, privateKey } = generateKeypair();
console.log('mnemonic:', mnemonic);
console.log('npub:', pubkeyToNpub(publicKey));
const enc = encryptPrivateKey(privateKey, 'test');
const dec = decryptPrivateKey(enc, 'test');
console.log('round-trip:', Buffer.from(dec).equals(Buffer.from(privateKey)));
const msg = sha256(new TextEncoder().encode('hello'));
const sig = schnorrSign(privateKey, msg);
console.log('verify:', schnorrVerify(publicKey, msg, sig));
"
```

## What the next sub-task needs to know
- Import from `@boilerdeck/auth`: `import { generateKeypair, encryptPrivateKey, ... } from "@boilerdeck/auth"` (re-exported from index.ts)
- Or directly: `import { ... } from "./crypto.js"` within the auth package
- `publicKey` and `privateKey` are `Uint8Array` (32 bytes each). Use `pubkeyHex()` to get the hex string for DB storage.
- `encryptPrivateKey` / `encryptMnemonic` return a `string` in `v1:...` format — store directly in DB text columns.
- `schnorrSign` expects a **pre-hashed** 32-byte message (SHA-256 digest), not raw message bytes. Hash first with `sha256()` from `@noble/hashes/sha2.js`.
- `sha256()` from `@noble/hashes` v2 requires `Uint8Array` input, not strings.
