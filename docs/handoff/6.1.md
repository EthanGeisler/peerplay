# Sub-task 6.1 — Privacy Settings Store Schema and IPC

## What was built
- **`client/src/main/store.ts`** (MODIFIED) — Added `PrivacySettings` interface, `DEFAULT_PRIVACY_SETTINGS` constant, and `privacySettings` field to `StoreData`. Added `"privacySettings"` to `STORE_KEY_WHITELIST`.
- **`client/src/main/index.ts`** (MODIFIED) — Added 4 IPC handlers: `privacy:get-settings`, `privacy:save-settings`, `privacy:get-status`, `privacy:test-connection`.
- **`client/src/main/preload.ts`** (MODIFIED) — Exposed all 4 privacy IPC channels under `window.boilerdeck.privacy`. Updated `declare global` type declarations.
- **`client/src/renderer/env.d.ts`** (MODIFIED) — Added `privacy` namespace with all 4 IPC channel type declarations.

## Key decisions made during implementation

- **Default mode is `"off"`.** No proxy is active until the user explicitly enables it. `DEFAULT_PRIVACY_SETTINGS` is exported from store.ts so IPC handlers can return sensible defaults when no settings have been saved yet.

- **`privacy:get-settings` returns defaults if nothing stored.** Uses nullish coalescing (`??`) against `DEFAULT_PRIVACY_SETTINGS` so callers always get a complete object, never null.

- **`privacy:test-connection` is a placeholder.** Returns `{ success: false, error: "Not implemented yet" }`. Will be wired to proxyManager in sub-task 6.2.

- **`privacy:get-status` is derived, not stored.** Computes `proxyActive` from the current mode (`mode !== "off"`). This avoids stale status if settings change.

- **`PrivacySettings` and `DEFAULT_PRIVACY_SETTINGS` are exported** from store.ts so they can be imported by index.ts (and later by proxyManager in 6.2).

## How it works

### IPC Channels
| Channel | Direction | Description |
|---|---|---|
| `privacy:get-settings` | renderer → main | Returns full `PrivacySettings` object (or defaults) |
| `privacy:save-settings` | renderer → main | Persists settings to JSON store |
| `privacy:get-status` | renderer → main | Returns `{ mode, proxyActive }` |
| `privacy:test-connection` | renderer → main | Placeholder (returns not-implemented error) |

### Preload Bridge
All channels exposed under `window.boilerdeck.privacy`:
```typescript
window.boilerdeck.privacy.getSettings()
window.boilerdeck.privacy.saveSettings(settings)
window.boilerdeck.privacy.getStatus()
window.boilerdeck.privacy.testConnection()
```

### PrivacySettings Schema
```typescript
{
  mode: "off" | "tor" | "socks5",
  socksHost: string,
  socksPort: number,
  socksUsername?: string,
  socksPassword?: string,
  routeApiTraffic: boolean,
  routeTorrentTraffic: boolean,
}
```

## Gotchas and surprises

- **Type declarations in two places.** The `privacy` types must stay in sync between `preload.ts` (declare global) and `env.d.ts`. The renderer tsconfig doesn't include preload.ts, so env.d.ts is the source of truth for the renderer.

- **`socksUsername` and `socksPassword` are optional.** They only apply when mode is `"socks5"` and the proxy requires authentication. Tor mode uses fixed defaults (127.0.0.1:9050, no auth).
