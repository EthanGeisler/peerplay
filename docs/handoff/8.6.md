# 8.6 — Client: Relay Management UI

## What was done

Added relay management to the Electron client, allowing users to view, add, remove, and toggle relays from the Settings page.

### Store (`client/src/main/store.ts`)
- Added `RelayEntry` interface: `{ url, name, isDefault, enabled }`
- Added `DEFAULT_RELAYS` constant (BoilerDeck relay)
- Added `relays?: RelayEntry[]` to `StoreData`
- Added `"relays"` to `STORE_KEY_WHITELIST`

### IPC Handlers (`client/src/main/index.ts`)
- `relays:list` — Returns relay list from store (initializes with default if empty)
- `relays:add` — Validates URL format (must be wss:// or ws://), fetches `/api/relay/info` via HTTPS to confirm relay is reachable, prevents duplicates, adds to store
- `relays:remove` — Removes relay (blocks removal of default BoilerDeck relay, returns `{ error }`)
- `relays:toggle` — Enables/disables a relay by URL

### Preload Bridge (`client/src/main/preload.ts`)
- Added `relays` namespace with `list`, `add`, `remove`, `toggle` methods

### Type Declarations (`client/src/renderer/env.d.ts`)
- Added matching `relays` type declarations to `window.boilerdeck`

### Settings UI (`client/src/renderer/pages/Settings.tsx`)
- New "Relays" section between "Privacy & Network" and "About"
- Shows each relay with: name (bold), URL (monospace), green/gray status dot, enable/disable toggle
- Remove button (hidden for default relay)
- Add Relay input + button with validation error display
- Info box explaining relays and default relay protection
